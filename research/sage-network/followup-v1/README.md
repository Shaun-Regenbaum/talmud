# Check the passages that still need work

This research follows the 42-passage pilot. It starts with the twelve cases where
review found a missing claim, a wrongly attached phrase, or another important
reading problem. Each case gets the wider text, available translations and
relevant commentaries.

The seven relationship families remain: family, transmission, teaching, speech,
views, scenes and time. The question is what each passage actually supports.
A quoted teacher is not automatically someone the speaker met. A legal example
is not automatically an event. An unnamed woman still has her own local identity.

## Read a case

Each finished folder under `cases/` contains `reading.md`, `dossier.json` and
saved source files. The dossier links every proposed finding to source words.
It keeps alternative readings, unresolved questions and proposed corrections.
`previous-review.json`, where present, is the earlier review copied unchanged.

These are research proposals. The old readings remain unchanged. No result here
by itself approves a historical person merge or a calendar date. Source research
and checks of file structure are separate from independent review of a conclusion.

## Inputs

The frozen input is `sage_network` lake snapshot 2, catalogued as
`talmud/sage-network-lake` version 3. The pilot is saved as
`talmud/sage-network-passage-pilot` revision 1. Public sources fetched during this
round record their addresses, saved bytes and hashes. A new fetch of the same
edition is not an independent historical witness.

`queue.json` records the starting questions. `baseline-hashes.json` records all
files in the earlier pilot before this research round. Research is saved case by
case so unfinished work can be resumed without losing completed readings.
