# The plan

`plan.html` is the review of the work so far and the plan from scratch: the
sources, the stages, what is pulled out of each mention, what is joined to
what, how each step is checked, and the decisions that are still open.

```
python3 build.py      # rebuilds plan.html from data.json, girsa.json, body.html, style.css
```

Every figure on the page is in `data.json` or `girsa.json`. `girsa.json` is the
comparison of two editions of tractate Berakhot in each Talmud, produced from
the fetched snapshot.
