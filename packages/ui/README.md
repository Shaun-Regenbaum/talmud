# @corpus/ui

The look-and-feel layer both readers import: design tokens, a theme per app, and Solid components. Logic stays in `@corpus/core`; this package is only what a page looks like.

## Layout

| File | What it is |
| --- | --- |
| `src/tokens.css` | The one variable vocabulary (colours, type, radius, shadows) every app uses |
| `src/themes/talmud.css`, `src/themes/tanach.css` | Per-app overrides: palette and Hebrew typeface |
| `src/components.css` and the `.tsx` files | The kit: `Button`, `Pill`, `Drawer`, `Prose`, `LangToggle`, `AiStatusBanner`, `LoadProgress`, `InspectorRow` |
| `src/GeoMap.tsx`, `src/WorldBubbleMap.tsx`, `src/geo/` | The shared map, its basemap and world geometry (generated by `scripts/`) |
| `src/RunTree*.tsx`, `src/RunWaterfall.tsx`, `src/UsagePage.tsx` | The build-tree and usage views |
| `src/aiStatus.ts`, `src/format.ts` | Small shared helpers |

Everything is exported by path from `package.json` (`@corpus/ui/Pill`, `@corpus/ui/tokens.css`). The package ships Solid `.tsx` as source; the apps exclude it from dependency pre-bundling so the JSX transform runs on it.

## Checks

```bash
pnpm --filter @corpus/ui typecheck
```
